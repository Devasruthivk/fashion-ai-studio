About this project

How it works

  1. You upload a JPG, PNG, or WEBP image.
  2. It's resized in your browser and sent to a secure server function.
  3. The server asks the Roboflow model (ViT, trained on 3 defect classes) for a score per class.
  4. You see the top class with a trust level: high, medium, or low.

Understanding the confidence

High: top score 60% or more and clearly ahead. Medium: 45% or more with a small lead. Low: the model is unsure, so take a clearer photo or check by eye.
